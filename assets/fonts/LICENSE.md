# Embedded typefaces

All three families are licensed under the SIL Open Font License 1.1, which
permits embedding in a document.

- **Archivo** — Omnibus-Type. https://github.com/Omnibus-Type/Archivo
- **Source Serif 4** — Adobe. https://github.com/adobe-fonts/source-serif
- **IBM Plex Mono** — IBM. https://github.com/IBM/plex

Latin subsets only, taken from the same builds the portfolio site uses so the
dashboard and the site share one typographic identity.
